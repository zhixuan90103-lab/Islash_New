# 切割拼图 — 玩法

> **当前玩家面对的玩法。** 第一关基础循环已接上。  
> 刀法：[SLASH-INTENT.md](./SLASH-INTENT.md)。几何 / 倒角：[SLASH-DESIGN.md](./SLASH-DESIGN.md)。  
> 参数：`src/game/design.ts` 的 `PUZZLE`。编排：`src/game/cutPuzzle.ts`，由 `slashWorld.ts` 挂上。

## 一句话

底上有凹槽。从料上切出图案，按进槽里，凑成完整样式。

## 包装（样式会换，规则不换）

杯子、圆盘、地板都只是一张皮。重点永远是：**凹槽在图上 → 切出能坐下的那块 → 贴回去 → 样式完整。**  
现在桌上的缺角圆只是验证刀、槽、镶嵌，不代表最终图案。后面换哪张完整样式（鸡尾酒、拼花、招牌……）都不改这一刀。

## 现在能玩的循环

```
展示：完整圆底盘 + 缺右上角的木色块（凹槽就是缺口）停约 2.2 秒
        ↓  等比缩小到右上角当缩略图（倒角一起缩，斜角仍约 45°）
方板从上方滑入工位
        ↓  限刀快划（A–B 贯穿；大留小飞）
点缩略图交卷（至少一刀之后），或 3 刀用尽
        ↓  缩略图放大回中央
切下来的角（与余料比谁更像扇形）直角顶到圆心，两边贴缺口半径
        ↓  停一下看齐不齐
出星 → 同一关再来一轮
```

进度条和「调试参数」面板当前不挂。没有任务字。  
顶上一排短条 = 剩余刀数（亮还能切，暗已用过）。  
缺角圆压在完整圆底盘上，右上缺口是凹槽，切出来的角坐进这口槽。

## 核

- 滑动把一块分成两区：工位上留下较大块；较小块飞走当废料。  
- 镶进缺口的是**更像四分之一圆的那一块**（通常是切下来的角），不是拿整块余料去乱转。  
- 直角顶点对准圆心，两条边贴缺口的横半径、竖半径。不搜任意转角。  
- 安装不用手塞。

## 第一关（已落地）

| 项 | 值 |
|----|-----|
| 图 | 完整圆底盘 + 缺右上四分之一的木块。凹槽就是要补的口 |
| 母料 | 方形木板（`wood.spawnSquare`） |
| 展示 | `PUZZLE.showDur`（2.2s） |
| 缩略图 | 右上；`scale.setScalar(thumbScale)`，XYZ 同比 |
| 干净刀数 | 2 |
| 最多刀数 | 3 |
| 交卷 | 点缩略图，或刀数用尽 |
| 过关 | 有星；目前回到展示，还没有第二关 |

拼图关里**不会**因体积低于 1/10 就两块都飞、换图库下一板。

## 外观

缺角圆用 `createChamferedSolid`（凹轮廓正面内收倒角，与木板同一配方），材质共用 `wood.faceMat` / `edgeMat`。不是红图标、不是薄片。

## 评分

无文字。三档合成星：满（缺口盖住多少）、齐（有没有越出）、干净（是否在干净刀数内）。多用一刀降一档。有星即可，低星仍循环本关。

## 难度（记下，未做关卡表）

多块、多色是手段，随时可加。真正加难是换这一刀在问的问题。一关只拧一两条。

缺口刁 · 母料不像 · 大小要对 · 刀数 · 记忆松紧 · 过切 · 镶嵌公差 · 朝向 · 假线索。

第二关不要重复「再切一个四分之一」。加色不是第二关必须的身份。

## 刻意不做

纸质拼图齿、描轮廓、飞来的果子、割绳子骨架、标签格子、拖拽归位、没切就交卷、镶上再改刀。
