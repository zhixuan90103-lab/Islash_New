# 划切意图识别规范

参数真源：`src/game/design.ts`（`START` / `INTENT` / `FLASH` / `TRAIL`）。  
状态机：`src/game/slashIntent.ts`（`stepSlashIntent`）。  
本划状态：`src/game/slashInput.ts`（`progress` / `follow`）。余势：`src/game/slashFollow.ts`。  
几何：`src/game/slashHit.ts`。绘制：`src/game/slashDebug.ts`。  
玩法总则：[SLASH-DESIGN.md](./SLASH-DESIGN.md)。

本文是**当前已落地规则**，不是待办。

## 总纲

1. **切开** = 从当前这块轮廓**一边**的入点 A，贯穿到**另一边**的出点 B。同边进出不算。没有 A 不切。切线这一侧拿走的都算这一刀。
2. **边** = 当前这块外轮廓上的边，切开后重数，不跟圆/方/菱形锁死。
3. **够直**：锁 A 后板内路程 / A→B 直线 > `START.pathChordMax`（默认 **1.5**）→ 这刀取消。钉死到出板或抬手。
4. **帮助** = 锁 A，并指出 B。B 不锁死。沿 AB：快 **98%**、慢 **100%** 可交刀。快划也是先入板锁 A。
5. **刀光**：对准青线且行程达到可交刀档可提前闪；已提前闪则切开不再闪；取消/失败不闪。一刀最多一次。
6. **入板才锁 A，出板就清，板心不锁。** 弧线余势不锁新 A；短距离尖角后可贴边锁第二刀。

## 原则

1. **宁可不帮助，但要精准。** 不确定就不补出点。
2. **有贯穿趋势且有 A 才切。** 乱划过的同一刀即使后来穿出去也不切。
3. **提交和反馈分开。** 夹缝 / 刀光不是切开。
4. **帮助只管 A 和 B。** 同一套速度尺子。
5. **一划不是一次按下。** 一次按下可以多刀。还在留下块上不锁新 A、不切。

## 三层

| 层 | 何时生效 | 失败时 |
|----|----------|--------|
| **提交** | 已有 A，进出两条不同边，够直 | 同边 / 乱划 / 无 A |
| **帮助** | 入板锁 A；对准青线且行程 ≥ T(速度) 则补出点 | 不帮：等真入边 / 真出边 |
| **余势** | 网格切开成功后 `beginFollow` | 切开失败不写。尾巴不锁新 A |

速度越快，终点 T 越低。最慢 T = **100%**。满速 T = **98%**。

## 几何用语

| 名 | 定义 |
|----|------|
| **青线** | 入点 A 沿当前刀向无限直线裁凸包。B 是青线出点。 |
| **行程** | 手指在青线上的投影 / 青线全长。终点帮助与提前刀光都用 `T(速度)`。 |
| **夹缝** | 入边 A → 当前刀尖（裁在包内）。 |
| **A** | 本刀入点。只在入板时写入。入边号一起锁死。屏上位置每帧重投，不重找边号。 |
| **余势** | 刚切开的缝 + 留下块。不跟飞出块。 |
| **走廊** | 整段到该缝距离 ≤ `START.corridor`，且方向点积 > `alongMin`。 |

## 提交（必须切）

1. **入板才有 A**。板心按下不锁 A，从中间拖出去不记刀。没有 A 不切。
2. **出另一条边**（或快划沿 AB 补出点）。同一条边进出不算。
3. **不在余势里**（刀尖还在留下块上，或仍顺着缝）。
4. **板内不乱绕**：路程 / A→出点直线 ≤ `pathChordMax`（默认 **1.5**）。一超标本刀钉死：不切、夹缝收回、刀光不闪、镜头只推一次。出板或抬手才清 A。
5. **抬手停在板内不切。**
6. 网格切开失败不写余势，恢复 `progress`。出边微段跳过凸包时用 A→刀尖打穿出点。未切开就出板则清 A。

不做单独的「A→B 太短就不切」。擦边靠同边。

## 帮助（可以不帮）

速度尺子 `t = clamp(中位速度 / fastSpeed, 0, 1)`。青线补切、提前刀光、快滑藏缝共用。

### 起点 A

入板才锁，只写一次。入边号跟 A 一起钉死。出板、切开成功、抬手、mesh 没了才清空。板内不重新锁。板心不锁。

贴边发糊：这一划的**下手点**已经在板内、且离轮廓 ≤ 当前速度半径（最慢 `slowDist` 10px，满速 `fastDist` 60px）时，把 A 吸到刀尖最近边上。从板心滑向边再切：下手点离边太远，不吸。

真入板：从刀尖往回最近一次板外点与刀尖求交（约 `fastDist×3`）。

### 有效刀（多指）

最多 `START.maxStrokes`（3）指，**只有一把有效刀**。误触按着不动不算刀。谁成为有效刀，直到这指抬起都不换。刀痕、夹缝、切开、划板音、持续震只跟有效刀。

### 终点（青线）

须已有 A。B 随刀向挪，不锁死。`T = lerp(1.0, endTravelFast, t)`。真出另一条边不看 T，乱划钉死的仍不切。

## 余势（同一划的尾巴）

只在网格切开成功后 `beginFollow`。

1. 记下切开弦、留下块。飞出块不占用。
2. 刀尖还在留下块上，或仍顺着走廊甩：不锁新 A、不切。弧线慢慢转向仍算余势。
3. **短距离尖角**（回看 `cornerSpan` 的两段航向夹角约 ≥70°，中等尖角还要刀速掉一截）→ 结束余势。拐角那一段不切；之后可按刀尖贴边锁新 A。
4. 离开留下块且不再顺着：余势结束；结束的那一段也不交刀。再入板才锁新 A。
5. 抬手：`follow = null`。
6. 新锁 A = 下一刀。

## 反馈

绘制顺序（下→上）：**夹缝 → 刀光 → 手指划痕**。对缝调试彩线最上。

### 夹缝

- 从锁死的 A 画到刀尖，**不出板**。刀尖离开凸包立刻不画。
- 慢滑：终点跟刀尖。快滑（≥ `crackHoldSpeed`）且刀尖离锁 A 刀轴 > `crackLeave` 则藏缝。
- 入口宽、指尖细，色 `crackColor` `#b1591a`，透明度 `crackAlpha` 0.65。
- 进板即可画，不必等刀光锁定。
- 余势拦住时不对留下的新块跟手画夹缝。
- 乱划取消：夹缝从刀尖收回 A（`FLASH.crackRetract`），本刀不再画缝。出板再进的新刀才重新画。镜头推进再回位（`SHAKE.cancelPush`），并小幅左右晃（`SHAKE.cancelWobble`）。

### 刀光（`FLASH`）

- 纺锤：两头细、中间宽。方向跟夹缝。
- **提前闪**：已锁 + 对准青线 `aimSegs` 段 + 行程 ≥ 同一 T(速度)。每刀最多一次。最慢 T=100%，不会提前闪。余势拦住时没有青线，不提前闪。乱划钉死不出刀光。
- **提交闪**：本刀还没提前闪过，切开必须闪。乱划取消没有提交闪。

### 划痕（`TRAIL`）

时间制丝带。只画有效刀的触点。模块 `slashTrail.ts`。

### 对缝调试

`INTENT.debug = 1`：绿虚 = 凸包，青 = 青线，黄 = 本划第 1 刀，粉粗 = 第 2 刀，橙 = 余势，灰虚 = 刚清掉的余势，白 = 当前微段。乱划取消时 why 为 `乱划路程 N×`。

## 状态机

`stepSlashIntent` 每微段：速度样本 → 夹缝 → `resolveCutBySegment`（先 `stepFollow`）→ 青线 / 刀光锁 → 提前闪。

`slashWorld`：先定有效刀（钉到抬起）→ `setCrack` → `commit` 则切网格（成功才 `beginFollow`）→ 否则 `earlyFlash`。非有效刀不进意图。滑入中途切开：顿帧停表，恢复后从该高度继续滑，不补落。

相位：`idle` / `arming` / `track` / `aimed` / `hold`（余势拦住）。

## 参数表

### `START`

| 键 | 默认 | 作用 |
|----|------|------|
| maxStrokes | 3 | 同时按下触点上限；有效刀始终一把 |
| slowDist / fastDist | 10 / 60 | 贴边发糊吸 A 的半径（最慢 / 满速）；`fastDist×3` 仍作往回找板外点的路程上限 |
| fastSpeed | 160 | 速度尺子满档 |
| endTravelFast | 0.98 | 满速终点行程门槛（最慢为 1，即 100%） |
| scoreMin | 0.35 | 未用（板心打分已删） |
| lockSlop | 14 | 帮助噪声用；真入板几何交点立即锁 A |
| speedWindow | 4 | 中位速度段数 |
| corridor | 8 | 余势走廊半宽 |
| alongMin | 0.15 | 余势：段方向点积大于此才算顺着走 |
| cornerSpan | 32 | 尖角：回看两段航向的长度（px） |
| cornerDot | 0.34 | 两段航向点积低於此为尖角（≈70°） |
| cornerFlip | 0 | 更锐（≈90°+）可免减速 |
| cornerSlow | 0.75 | 中等尖角：当前刀速 ≤ 巡航 × 此值 |
| pathChordMax | 1.5 | 板内路程 / A→出点直线上限。调试面板「乱划路程比」 |
