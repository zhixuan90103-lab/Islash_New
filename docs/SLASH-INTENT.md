# 划切意图识别规范

参数真源：`src/game/design.ts`（`START` / `INTENT` / `FLASH` / `TRAIL`）。  
状态机：`src/game/slashIntent.ts`（`stepSlashIntent`）。  
本划状态：`src/game/slashInput.ts`（`progress` / `follow`）。余势：`src/game/slashFollow.ts`。  
几何：`src/game/slashHit.ts`。绘制：`src/game/slashDebug.ts`。  
玩法总则：[SLASH-DESIGN.md](./SLASH-DESIGN.md)。

本文是**当前已落地规则**，不是待办。

## 总纲

1. **切开** = 从当前这块轮廓**一边**的入点 A，贯穿到**另一边**的出点 B，并且这根手指已经抬起。同边进出不算。没有 A 不切。切线这一侧拿走的都算这一刀。抬手前 B 一直跟手指：纸内 B 在刀尖，纸外 B 是 A 穿过刀尖打到对面边上的交点。抬手才用当时的 A、B 切网格。
2. **边** = 当前这块外轮廓上的边，切开后重数，不跟圆/方/菱形锁死。
3. **取消**只在刀尖已经出纸、而且当前角度做不出有效切割时发生。纸里绕路不取消。出纸后只改角度，只要还能打到另一条边，就不取消。
4. **帮助** = 锁 A，并让 B 跟着当前刀尖。B 不提前交刀。入点贴着尖角时收到角中心，从边侧划入不收。
5. **刀光**只在抬手切开成功时沿最终的 A、B 闪一次。滑动过程中不闪。取消不闪。
6. **入板才锁 A，出板就清，板心不锁。** 弧线余势不锁新 A；短距离尖角后可贴边锁第二刀。

## 原则

1. **宁可不帮助，但要精准。** 不确定就不补出点。
2. **有贯穿趋势且有 A 才切。** 纸里绕路不影响。出纸后角度切不成，这一刀才取消。
3. **提交和反馈分开。** 夹缝 / 刀光不是切开。
4. **帮助只管 A 和 B。** 同一套速度尺子。
5. **一划不是一次按下。** 一次按下可以多刀。还在留下块上不锁新 A、不切。

## 三层

| 层 | 何时生效 | 失败时 |
|----|----------|--------|
| **提交** | 已有 A，进出两条不同边，抬手 | 出纸后切不成 / 无 A |
| **帮助** | 入板锁 A；对准青线且行程 ≥ T(速度) 则补出点 | 不帮：等真入边 / 真出边 |
| **余势** | 网格切开成功后 `beginFollow` | 切开失败不写。尾巴不锁新 A |

纸内不切。刀尖出纸且 A、B 在两条不同边上，抬手才切。

## 几何用语

| 名 | 定义 |
|----|------|
| **青线** | 入点 A 沿当前刀向无限直线裁凸包。B 是青线出点。 |
| **行程** | 手指在青线上的投影 / 青线全长。只给调试看，不提前交刀、不提前闪。 |
| **夹缝** | 入边 A → 当前刀尖（裁在包内）。 |
| **A** | 本刀入点。只在入板时写入。入边号一起锁死。屏上位置每帧重投，不重找边号。 |
| **余势** | 刚切开的缝 + 留下块。不跟飞出块。 |
| **走廊** | 整段到该缝距离 ≤ `START.corridor`，且方向点积 > `alongMin`。 |

## 提交（必须切）

1. **入板才有 A**。板心按下不锁 A，从中间拖出去不记刀。没有 A 不切。
2. **出另一条边**（或快划沿 AB 补出点）。同一条边进出不算。
3. **不在余势里**（刀尖还在留下块上，或仍顺着缝）。
4. **纸里不因为绕路取消。** 刀尖出纸后，A 穿过刀尖打不到另一条边，才取消：不切、夹缝收回、刀光不闪、镜头不动。出纸后改角度，只要又能打到另一条边，这一刀还在。
5. **抬手停在板内不切。** 只有刀尖已经在纸外、A 和 B 在两条不同边上，抬手才切。按着时出点可以继续改。
6. 网格切开失败不写余势，恢复 `progress`。出边微段跳过凸包时用 A→刀尖打穿出点。未切开就出板则清 A。

不做单独的「A→B 太短就不切」。擦边靠同边。

## 帮助（可以不帮）

速度尺子 `t = clamp(中位速度 / fastSpeed, 0, 1)`。只用于贴边吸 A 的半径和快滑藏缝。不用于提前交刀。

### 起点 A

入板才锁，只写一次。入边号跟 A 一起钉死。出板、切开成功、抬手、mesh 没了才清空。板内不重新锁。板心不锁。

贴边发糊：这一划的**下手点**已经在板内、且离轮廓 ≤ 当前速度半径（最慢 `slowDist` 10px，满速 `fastDist` 60px）时，把 A 吸到刀尖最近边上。从板心滑向边再切：下手点离边太远，不吸。

入点已经贴着尖角时，收到这个角的中心。范围大约 6 到 10 设计像素，不超过到下一个角距离的 16%。只认转得急的角，圆弧上的点不收。从边的一侧划入不收。倒角上挨得很近的几个尖，收到它们的中点。

蝴蝶辅助线已经长出来时，顺着线附近划会轻轻吸向这条线。离线远，或者横着穿过，不吸。

真入板：从刀尖往回最近一次板外点与刀尖求交（约 `fastDist×3`）。

### 有效刀（多指）

最多 `START.maxStrokes`（3）指，**只有一把有效刀**。误触按着不动不算刀。谁成为有效刀，直到这指抬起都不换。刀痕、夹缝、切开、划板音、持续震只跟有效刀。

### 终点（青线）

须已有 A。B 随刀尖挪，不锁死。纸内 B 在刀尖。纸外 B 是 A 穿过刀尖打到对面边上的交点。抬手前不交刀。

## 余势（同一划的尾巴）

只在网格切开成功后 `beginFollow`。

1. 记下切开弦、留下块。飞出块不占用。
2. 刀尖还在留下块上，或仍顺着走廊甩：不锁新 A、不切。弧线慢慢转向仍算余势。
3. **短距离尖角**（回看 `cornerSpan` 的两段航向夹角约 ≥70°，中等尖角还要刀速掉一截）→ 结束余势。拐角那一段不切；之后可按刀尖贴边锁新 A。
4. 离开留下块且不再顺着：余势结束；结束的那一段也不交刀。再入板才锁新 A。
5. 抬手：`follow = null`。
6. 新锁 A = 下一刀。

## 反馈

整张特效画在画面最上层（盖过纸和按钮），不吃点击。层内从下到上：**夹缝 → 刀光**。手指划痕现在不画（`TRAIL.show = 0`）。对缝调试彩线最上。

### 夹缝

- 从锁死的 A 画到当前出点。纸内出点是刀尖。纸外出点是 A 穿过刀尖打到对面边上的交点。快转角度时不藏缝，线留在上一帧的出点上，直到新的出点算出来，或者这一刀取消。
- 样子和提示一样：入点一个白圆点，中间白虚线，刀尖一个白圆点。圆点半径 0.026，虚线宽 0.013，一截 0.08、空 0.045。乱划收回时整条一起淡出。
- 进板即可画，不必等刀光锁定。
- 余势拦住时不对留下的新块跟手画夹缝。
- 出纸后切不成才取消：夹缝从刀尖收回 A（`FLASH.crackRetract`），本刀不再画缝。再进纸是新刀。取消时镜头不动。

### 刀光（`FLASH`）

- 纺锤：两头细、中间宽。方向跟夹缝。颜色跟这一刀底下的料，再往白色提一截；外发光用料色。碎屑也用料色。乌龟上半深绿、下半浅绿，按刀经过的位置取。
- **切开闪**：抬手切开成功时沿最终的 A、B 闪一次。滑动中不闪。出纸后切不成没有刀光。

### 划痕（`TRAIL`）

时间制丝带。只画有效刀的触点。模块 `slashTrail.ts`。

### 对缝调试

`INTENT.debug = 1`：绿虚 = 凸包，青 = 青线，黄 = 本划第 1 刀，粉粗 = 第 2 刀，橙 = 余势，灰虚 = 刚清掉的余势，白 = 当前微段。出纸后切不成时 why 以 `取消` 开头。

## 状态机

`stepSlashIntent` 每微段：速度样本 → 夹缝 → `resolveCutBySegment`（先 `stepFollow`）→ 青线只给调试。滑动中不闪刀光。

`slashWorld`：先定有效刀（钉到抬起）→ 滑动时 `setCrack` 画出跟手的 A、B → 抬手调用 `cutOnRelease` 才切网格并闪刀光（成功才 `beginFollow`）。帧循环不改这条缝。非有效刀不进意图。滑入中途切开：顿帧停表，恢复后从该高度继续滑，不补落。

相位：`idle` / `arming` / `track` / `aimed` / `hold`（余势拦住）。

## 参数表

### `START`

| 键 | 默认 | 作用 |
|----|------|------|
| maxStrokes | 3 | 同时按下触点上限；有效刀始终一把 |
| slowDist / fastDist | 10 / 60 | 贴边发糊吸 A 的半径（最慢 / 满速）；`fastDist×3` 仍作往回找板外点的路程上限 |
| fastSpeed | 160 | 速度尺子满档 |
| endTravelFast | 0.98 | 满速终点行程门槛（最慢为 1，即 100%） |
| scoreMin | 0.35 | 未用（板心打分已删） |
| lockSlop | 14 | 帮助噪声用；真入板几何交点立即锁 A |
| speedWindow | 4 | 中位速度段数 |
| corridor | 8 | 余势走廊半宽 |
| alongMin | 0.15 | 余势：段方向点积大于此才算顺着走 |
| cornerSpan | 32 | 尖角：回看两段航向的长度（px） |
| cornerDot | 0.34 | 两段航向点积低於此为尖角（≈70°） |
| cornerFlip | 0 | 更锐（≈90°+）可免减速 |
| cornerSlow | 0.75 | 中等尖角：当前刀速 ≤ 巡航 × 此值 |
