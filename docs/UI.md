# 画面与界面

> **竖屏桌子的视觉真源。** 玩法仍走 [CUT-PUZZLE.md](./CUT-PUZZLE.md)。  
> 设计框是竖屏 390×844。笔记本、镜头和图标还没接到正在跑的画面上。改画面以本页为准。  
> 草图只定方向；生成图不作准。

## 一句话

整局竖屏。图纸画在打开的笔记本上，料放在右边的裁剪区。镜头在这两边之间平移。步数、撤销、提示是图标，「装上」写字。图纸是扁平剪影，纸是纯色。看起来像手绘纸卡小游戏。

方向一旦选定，看图、切、摆都用这一个方向。不中途转屏。

## 桌子怎么摊

世界从左到右排开：左边是笔记本，右边是裁剪区。镜头一次只对着其中一边。

| 地方 | 放什么 |
|------|--------|
| 笔记本 | 这一关要做的图案。已装零件显色，要切的零件是剪影 |
| 裁剪区 | 这一关的料。切开的块留在这里，直到带着它们回到笔记本 |
| 蓝底边上 | 工具图标。不压本子，不压纸 |

## 镜头

镜头只会自己走两次。中间不能拨。

1. **看图。** 镜头对着左侧笔记本上的剪影。停 2 秒。这时看不见料。
2. **去切。** 2 秒到了，镜头自动向右滑进裁剪区。切的时候看不见图。
3. **切完出「装上」。** 右上角一直有步数。要的轮廓都出现，或步数用完，下沿正中弹出「装上」。还有步就可以再切，按钮不收回。
4. **点「装上」。** 刀停下。切下来的块跟着镜头一起滑回左侧笔记本。
5. **拼。** 在这一页上拖、转、贴。
6. **拼完。** 界面这时才弹出来。

## 阶段只留这一阶段的东西

| 阶段 | 镜头对着 | 画面上有什么 |
|------|----------|------|
| 看图 | 笔记本 | 都收着 |
| 切 | 裁剪区 | 步数、撤销、提示。齐了或步用完再出「装上」 |
| 拼 | 笔记本 | 撤销。步数和提示离开 |
| 拼完 | 笔记本 | 弹出界面 |

## 图标

步数、撤销、提示不写字。「装上」写这两个字。

| 作用 | 位置 | 图形 |
|------|------|------|
| 还剩几步 | 右上角 | 几个圆点，一点一步。切的时候一直在，装上出现后也在 |
| 撤销 | 左下角 | 回转箭头。切的时候退一刀，拼的时候退一次拖动或旋转 |
| 提示 | 右下角 | 一小段虚线。只在切的时候 |
| 装上 | 下沿正中 | 按钮，写着「装上」。点了才带着块和镜头回笔记本 |

点提示，料上画出白色虚线：蝴蝶一条竖线；乌龟一条横线，再加下半圆里一条竖线。再点一次，虚线消失。

## 图纸长什么样

扁平几何剪影，不是写实动物，不是照片。

- 蝴蝶：两只眼睛有色。左右翅膀是剪影。
- 乌龟：头和眼睛有色。壳是半圆剪影。两条腿是四分之一圆剪影。

## 纸长什么样

薄、软、纯色。侧面跟正面同一个颜色，不单独露棱。

- 蝴蝶：纯粉圆。
- 乌龟：上半深绿、下半浅绿。

## 风格

手绘纸卡。浅蓝底、纸的颗粒、圆角、描边。轻松小游戏。

不要照片光影。不要木纹底。不要红底道场。不要血条、飘分、任务栏。
