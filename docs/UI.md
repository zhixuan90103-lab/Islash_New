# 画面与界面

> **竖屏桌子的视觉真源。** 玩法仍走 [CUT-PUZZLE.md](./CUT-PUZZLE.md)。  
> 设计框是竖屏 390×844。看图、滑到裁剪区、点「装上」后连块一起回去，拼的时候点「完成」出星。  
> 草图只定方向；生成图不作准。

## 一句话

整局竖屏。图纸画在程序画的笔记本上，料放在右边的裁剪区。镜头在这两边之间平移。切的时候左上角是 Moves 和剩余步数，右上角是齿轮。撤销、提示是图标，「装上」和「完成」写字。图纸是扁平剪影，纸是纯色。看起来像手绘纸卡小游戏。

方向一旦选定，看图、切、摆都用这一个方向。不中途转屏。

## 桌子怎么摊

世界从左到右排开：左边是笔记本，右边是裁剪区。镜头一次只对着其中一边。

| 地方 | 放什么 |
|------|--------|
| 笔记本 | 程序画的活页本，都有厚度。蝴蝶外皮 `#db96a8`、内页 `#fef2df`。乌龟外皮 `#93af48`、内页 `#fff9e4`。鱼外皮 `#908db8`、内页 `#f4f1fb`。默认略逆时针。已装零件显色，要切的零件是剪影 |
| 裁剪区 | 这一关的料。切开的块留在这里，直到带着它们回到笔记本。镜头按料的缩放推近，让料在画面里仍是改比例之前的大小 |
| 棋盘边上 | 工具图标。不压本子，不压纸 |

## 镜头

镜头只会自己走两次。中间不能拨。

1. **看图。** 镜头对着左侧笔记本上的剪影。停 2 秒。这时看不见料。
2. **去切。** 2 秒到了，镜头自动向右滑进裁剪区。切的时候看不见图。
3. **切完出「装上」。** 第一关先出一行字：「在规定步数内裁剪出蝴蝶翅膀」。这时步数和齿轮还在屏幕外。这行字显示 2 秒，或玩家点一下屏幕，就在原地淡出，步数和齿轮再进来。要的轮廓都出现，或步数用完，下沿正中弹出「装上」，虚线同时消失。还有步就可以再切，按钮不收回。
4. **点「装上」。** 刀停下。切下来的块跟着镜头一起滑回左侧笔记本。
5. **拼。** 第一指选中一块，并记下它的轮廓中心。一指拖，中心跟着走。两指时中心跟两指中点走，旋转绕这个中心。抬起一根不改位置。不吸。细则 [CUT-PUZZLE.md](./CUT-PUZZLE.md)「拼放手势」。
6. **拼完。** 下沿正中是「完成」。点了才按现在的摆法计分，弹出结算。三颗浅灰实心星一直在。得到的黄色星从左到右盖上去，间隔 0.3 秒。重玩是灰圆，下一关是蓝圆。

## 阶段只留这一阶段的东西

| 阶段 | 镜头对着 | 画面上有什么 |
|------|----------|------|
| 看图 | 笔记本 | Moves 和齿轮向上移出。撤销、提示收着 |
| 切 | 裁剪区 | 第一关先是目标字。淡出后才是 Moves、齿轮。撤销、提示一直在。齐了或步用完再出「装上」，虚线消失 |
| 拼 | 笔记本 | 撤销、「完成」。Moves 和齿轮已移出，提示离开。图案阴影留着 |
| 拼完 | 笔记本 | 白色弹窗。灰底星常在，黄星逐个盖上。重玩灰、下一关蓝。阴影不藏 |

## 图标

撤销、提示、设置是图标。步数写成 Moves 和数字。「装上」「完成」写字。字和图标是灰色 `#6b7280`，白按钮下面是同一道浅灰影子。都躲开顶部安全区。

镜头滑向笔记本时，Moves 和齿轮一起向上移出。滑进裁剪区时，第一关先只进目标字；字淡出后，Moves 和齿轮再进来。乌龟和鱼没有这行字，滑进裁剪区时步数和齿轮直接进来。

| 作用 | 位置 | 图形 |
|------|------|------|
| 还剩几步 | 左上角 | 圆角卡片。上面 Moves，下面数字。第一关等目标字淡出后才进来 |
| 设置 | 右上角 | 齿轮。打开可调外皮、内页、图案阴影 |
| 撤销 | 左下角 | 返回箭头。切的时候退一刀，拼的时候退一次拖动或旋转 |
| 提示 | 右下角 | 灯泡。只在切的时候 |
| 装上 | 下沿正中 | 按钮，写着「装上」。只在切的时候。点了才带着块和镜头回笔记本 |
| 完成 | 下沿正中 | 按钮，写着「完成」。只在拼的时候。点了才计分，弹出结算。不藏图案阴影 |

点灯泡，料上画出白色虚线：蝴蝶一条竖线；乌龟一条横线，再加下半圆里一条竖线。鱼没有虚线。再点一次，虚线消失。蝴蝶进裁剪区时虚线默认就在。轮廓齐了或步数用完，虚线隐藏。

## 图纸长什么样

扁平几何剪影，不是写实动物，不是照片。

- 蝴蝶：每只眼睛两层。底下是阴影色的圆，比眼珠大到 1.8 倍。上面是 `#c7c77f` 的眼珠。两片大翅膀比纸大 20%，圆心外移到两边相接，颜色 `#c98496`，完全不透明。和纸一样大的两片黑半圆盖在上面，透明度 30%，圆心比大翅膀再向内一截。大翅膀下沿有一块和裁切片一样的落影。
- 乌龟：不另转角度。头是浅色 `#cee2ab`，眼睛是深色。壳和两条腿有两层影子：外层 `#5f7828`，完全不透明，绕各自圆心放大 20%；内层是黑色，默认透明度 30%。头后面还有一圈同样的深色外轮廓。头、眼睛和大翅膀一样，正面有纸纹，下面有和裁切片一样的落影。整只按轮廓对齐内页中心。
- 鱼：七块都是要切的零件，粉色 `#fbcad6`。每块下面有一层同轮廓的外影 `#8a88b0`。身子放大 1.15 倍，头、尾和四块鳍放大 1.2 倍。没有眼睛，没有半圆。
- 图案相对设计尺寸缩到 80%。本子不跟着这 80% 变。裁切的纸按同一比例生成，所以和阴影一样大。拿起纸片时放大到 1.05，松手缩回。

## 纸长什么样

薄、软。侧面跟正面同一个颜色，不单独露棱。正面先铺颜色，再压一层细纸纹。料已经在裁剪区里，没有从画面外滑进来的动画。镜头滑过去就是入场。

- 蝴蝶：`#fbcad6` 的圆。
- 乌龟：上半 `#93af48`，下半 `#cee2ab`。
- 鱼：`#b4b3dc` 的菱形。尖朝上、下、左、右。

笔记和切下来的料用同一套落影：向右、向下。放回笔记本后，纸片影子在外皮、内页和参考图前面，贴在纸片下面，偏移收到裁切时的四成。料的影子不互相压边。

## 风格

手绘纸卡。背景是钉在世界里的棋盘格。一屏横 4 格、竖 9 格，边落在格子线上。蝴蝶是浅蓝 `#afc4d9` / `#abc0d5`。乌龟是浅粉 `#f2c8cb` / `#e7bdc0`。鱼是浅紫 `#e3e1f3` / `#d4d2e8`。四角压暗，中间的本子和料不压暗。轻松小游戏。

不要照片光影。不要木纹底。不要红底道场。不要血条、飘分、任务栏。

## 代码现状

运行的是竖屏。镜头在程序笔记和裁剪区之间自己滑。料没有落入动画。第一关先出一行目标字，再进 Moves 和齿轮。右下角眼睛可以随时回到预览，预览不限时，点画面才继续。点眼睛时齿轮留在画面上。撤销是返回箭头，提示是灯泡。蝴蝶的虚线默认开着，可以装上时关掉。鱼没有虚线。「装上」和「完成」写字。拼的时候一指拖、两指绕选中时记下的中心转。点「完成」后出结算弹窗，阴影留着。齿轮可以改笔记本、图案阴影、划痕，以及乌龟各块和内外影。刀光长度是这一刀的 1.3 倍。`?edit=1` 打开关卡编辑器：参数和工具在手机画面左侧，可以收起。
